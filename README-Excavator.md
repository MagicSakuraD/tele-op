# 挖掘机远程控制系统

基于 WebRTC 的低延迟重型机械远程驾驶系统，允许操作员通过标准 Web 浏览器实时操控远端的挖掘机等重型机械。

## 系统架构

### 1. 远程操作台 (Operator Console)
- **平台**: 任何支持 WebRTC 的现代 Web 浏览器
- **技术栈**: Next.js + React + LiveKit
- **功能**: 实时视频接收 + 手柄控制指令发送

### 2. 云端核心 (LiveKit Server)
- **服务器**: LiveKit 媒体服务器 (SFU)
- **功能**: 视频流转发 + 控制指令中继
- **部署**: 本地部署在端口 7880

### 3. 挖掘机端 (Edge Node)
- **设备**: 挖掘机上的边缘计算设备
- **功能**: 视频采集 + 控制指令接收 + 机械执行

## 功能特性

### 🎮 手柄控制
- **左手柄**: 驾驶室旋转 (X轴) + 小臂伸缩 (Y轴) + 左履带 (轴9)
- **右手柄**: 铲斗开合 (X轴) + 大臂提降 (Y轴) + 右履带 (轴9)
- **死区处理**: 避免摇杆轻微晃动产生误操作
- **实时反馈**: 控制状态实时显示

### 📹 视频流
- **实时传输**: 基于 WebRTC 的低延迟视频流
- **自适应质量**: 根据网络状况自动调整视频质量
- **多参与者**: 支持多个操作员同时观看

### 🔄 数据通道
- **控制指令**: 通过 DataChannel 发送 JSON 格式的控制指令
- **可靠传输**: 使用可靠传输确保控制指令不丢失
- **实时性**: 毫秒级延迟响应

## 控制映射

| 控制项 | 手柄 | 轴 | 范围 | 说明 |
|--------|------|-----|------|------|
| 左履带 | 左手柄 | 轴9 | -1 ~ 1 | 前进/后退 |
| 右履带 | 右手柄 | 轴9 | -1 ~ 1 | 前进/后退 |
| 驾驶室旋转 | 左手柄 | X轴 | -1 ~ 1 | 左转/右转 |
| 大臂 | 右手柄 | Y轴 | -1 ~ 1 | 提升/下降 |
| 小臂 | 左手柄 | Y轴 | -1 ~ 1 | 伸出/收回 |
| 铲斗 | 右手柄 | X轴 | -1 ~ 1 | 翻斗/收斗 |

## 安装和运行

### 1. 启动 LiveKit 服务器
```bash
cd /root/Code/LiveKit
livekit-server --config config.yaml
```

### 2. 启动 Next.js 应用
```bash
cd /root/Code/LiveKit/NextLive/tele-op
npm run dev
```

### 3. 访问系统
- **主页**: https://cyberc3-cloud-server.sjtu.edu.cn
- **控制台**: https://cyberc3-cloud-server.sjtu.edu.cn/room

## 使用说明

### 1. 连接手柄
- 将两个手柄连接到电脑
- 系统会自动检测并映射控制

### 2. 进入控制台
- 点击"🚜 进入挖掘机控制台"
- 等待连接到挖掘机房间

### 3. 开始控制
- 左侧显示挖掘机实时视频
- 右侧显示控制状态
- 使用手柄进行精确控制

## 技术细节

```typescript
// 履带轴特殊值映射
```

```json
{
  "type": "excavator_control",
  "timestamp": 1640995200000,
  "controls": {
    "leftTrack": 0.5,
    "rightTrack": -0.3,
    "swing": 0.0,
    "boom": 0.8,
    "stick": -0.2,
    "bucket": 0.1
```

### 网络配置
- **WebSocket**: wss://cyberc3-cloud-server.sjtu.edu.cn/livekit
- **代理**: Next.js rewrites 将 /livekit/* 代理到本地 LiveKit 服务器
- **跨域**: 配置了 CORS 和 allowedDevOrigins

## 安全考虑

1. **访问控制**: 使用 API 密钥进行身份验证
2. **房间隔离**: 每个挖掘机使用独立的房间
3. **指令验证**: 挖掘机端应验证控制指令的有效性
4. **紧急停止**: 建议实现紧急停止机制

## 故障排除

### 手柄不响应
- 检查手柄是否正确连接
- 确认浏览器支持 Gamepad API
- 查看控制状态显示是否更新

### 视频无法显示
- 检查 LiveKit 服务器是否运行
- 确认挖掘机端已连接
- 查看浏览器控制台错误信息

### 连接失败
- 检查网络连接
- 确认域名解析正确
- 查看 LiveKit 服务器日志
